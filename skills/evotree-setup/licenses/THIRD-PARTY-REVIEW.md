# Bundled third-party runtime and notices

This native package includes CPython 3.12.14, its statically linked libraries,
embedded standard-library materials and Nuitka target-runtime code. It does not
require a second model API. It is not an all-original or wholly proprietary binary.

Unmodified license texts and the component/linkage inventory are installed under
licenses/third-party/. CPython historical licenses, HACL MIT, BLAKE2/CC0, OpenSSL,
bzip2, libffi, mpdecimal, Expat, liblzma, libuuid and SQLite notices are retained.

and NOTICE are included. The inline zlib CRC32 notice is included separately.
An upstream OpenSSL 1.1 notice is retained conservatively; observed SSL is 3.5.8.
System library links are distinguished from bundled static copies in COMPONENTS.
